# Blog Next

Projeto desenvolvido durante os estudos de **Next.js**, reunindo em um único projeto as atividades e conceitos praticados ao longo do curso.

## Sobre o projeto

O objetivo deste projeto é colocar em prática os principais conceitos aprendidos nos estudos de **Next.js**, servindo como um registro prático das atividades e conhecimentos desenvolvidos ao longo do aprendizado.

##  Tecnologias

- Next.js
- React
- CSS
- JavaScript

## Conceitos praticados

- Criação de páginas e componentes
- Rotas e navegação
- Estilização
- Organização da estrutura de um projeto Next.js
- Tratamento de erros
- Funções assíncronas com `async/await`

---

## Pré-requisitos 
Antes de executar o projeto, é necessário ter instalado: 

- Node.js 
- npm

## Como executar

Clone o repositório e instale as dependências:

```
npm install
```

Depois, execute o projeto:

```
npm run dev
```

A aplicação estará disponível em:

```
http://localhost:3000
```
